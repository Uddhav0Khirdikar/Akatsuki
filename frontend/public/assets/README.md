# Asset provenance

`crimson-hour.webp`, `crimson-hour-mobile.webp`, and `maple-foreground.webp` are local derivatives of the Itachi illustration available from [ChromeThemer](https://www.chromethemer.com/wallpapers/4k-wallpapers/itachi-best-wallpaper-4k.html).

Source image: https://www.chromethemer.com/download/hd-wallpapers/itachi-3840x2160.jpg

The image matches the red-maple Itachi scene in the user's supplied design reference. This implementation uses it as sourced reference artwork after the custom generation request failed with `credit_balance_exhausted`. No original artist attribution or commercial redistribution license was verified from the download source. Preserve this provenance when replacing or reviewing the artwork.

Local processing: downscale, modest saturation adjustment, WebP optimization, separate mobile crop, and a red-foliage alpha extraction for foreground depth. The character illustration itself is existing artwork.

`cloud.svg` is a code-created cloud mark. The metallic emblem, petals, lighting, and particles are generated by Three.js in `src/Atmosphere.tsx`.

The requested custom-art prompt is preserved at `ui/login/crimson-hour/artwork-prompt.txt`. A generated replacement can use the same filename and composition contract once API generation is available. No API credentials belong in this directory or the frontend bundle.
