# Akatsuki UI studio

This folder holds design ideas, visual studies, and refinement decisions for the future Akatsuki frontend. The audience is young college students finding opportunities and building teams.

The identity is specifically inspired by **Akatsuki**: crimson clouds, black fabric, bold silhouettes, and a collective of distinct people. Every exploration should connect that identity to the campus product.

The overall product direction lives in [the UI/UX plan](../docs/ui-ux-plan.md). The current design priority is login exploration, ahead of the Explore-screen studies originally proposed there.

**Start here**

- [Login exploration brief](login/00-brief.md): shared experience, content, interaction states, and evaluation criteria.
- [Visual comparison board](login/visuals/comparison.png) ([scalable SVG](login/visuals/comparison.svg)): six composition studies using the same sign-in task. These are schematic art-direction studies, not finished production screens.

**How to use the folder**

Keep new screen explorations in their own directory. Give each concept a stable number, a detailed brief, and associated visuals. Record iterations beside the original concept so comparisons remain possible. A selected direction should have a short decision note identifying what worked, what needs to change, and which traits carry into the app.

The briefs are proposals. Fonts, colors, dimensions, and timing are concrete starting points for testing. The SVG board uses system-font approximations and simplified artwork; the written briefs describe the intended finish.

This collection contains design artifacts. No authentication implementation or production frontend is included.
